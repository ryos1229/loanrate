# 住宅ローン金利チェック・ダッシュボード

このプロジェクトは、主要金融機関の住宅ローン金利をワンボタンで取得し、美しく可視化するためのツールです。

## 🚀 使い方

### 1. 最新金利の取得
ターミナルで以下のコマンドを実行するだけで、各銀行の最新金利を自動的に取得します。
```bash
npm run update
```

### 2. ダッシュボードの表示
以下のコマンドでダッシュボードを起動します（既に起動している場合は不要です）。
```bash
npm run dev
```
ブラウザで [http://localhost:5173/](http://localhost:5173/) を開いてください。

## ✨ 機能
- **ワンボタン更新**: スクリプトが自動的に各銀行のサイトを巡回し金利を取得。
- **美しく可視化**: 変動・固定金利の比較チャートや、最安値のハイライト機能。
- **絞り込み・並び替え**: 銀行名での検索や、金利順でのソートが可能。
- **プレミアムデザイン**: ダークモードとグラスモーフィズムを採用したモダンなUI。

## 🛠 構成
- **Frontend**: React, Tailwind CSS, Recharts, Lucide React
- **Automation**: Playwright (Web Scraper)
- **Data**: `src/data/rates.json`

---
*注：スクリプトのウェブサイト巡回ロジックの一部は雛形になっています。各金融機関のサイト構造の変更に合わせて `scripts/update-rates.js` を適宜調整してください。*
