# 住宅ローン金利比較ダッシュボード (2026年2月版)

主要金融機関の住宅ローン金利（変動・固定）を一覧・比較できるダッシュボードです。  
2026年2月の最新金利状況、特に短期プライムレート引き上げに伴う変動金利の改定状況を反映しています。

## 🌟 特徴

- **最新データの網羅**: メガバンク、信託、地銀、ネット銀行、信金、労金、JAなど主要機関をカバー。
- **実質金利・優遇幅の可視化**: 店頭表示金利と実質適用金利の差（割引幅）を一目で確認可能。
- **A4印刷・PDF出力最適化**: 比較表をA4縦1枚に綺麗に収めて印刷・PDF化できる専用レイアウトを搭載。
- **最新情報への簡単同期**: `rates.json` 形式でのデータ管理により、データの更新・メンテナンスが容易。

## 🛠 テクノロジー

- **Frontend**: React (Vite)
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Design**: グラスモーフィズム（ガラス質感）を採用したモダンUI

## 🚀 使い方

1. リポジトリをクローンまたはダウンロード
2. 依存関係のインストール: `npm install`
3. 開発サーバーの起動: `npm run dev`
4. ブラウザで [http://localhost:5173/](http://localhost:5173/) にアクセス

## 📝 データの更新方法

`src/data/rates.json` を編集することで表示内容を更新できます。
更新後は、画面右上の「最新情報を取得」ボタンをクリックして反映させてください。

---

※本ツールで提供される情報は調査時点のものです。実際の借入条件は必ず各金融機関の公式サイトで最新の情報をご確認ください。
